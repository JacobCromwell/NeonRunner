# Owner reference art

Concept images supplied by the owner to guide the code-built models. They are **references only**:
never shipped, never loaded by the game. The `.gdignore` file keeps Godot from importing this folder,
so the images stay out of every export.

| File | What it guides | Notes |
|---|---|---|
| `player_echo.jpg` | The player character (GDD §11) | Leave out the sword and the symbols on the coat's lower half (graffiti and the skull emblem). |
| `cyborg_viewing_devices.jpg` | The cyborg gangsters (GDD §9.2) | **Variant 1, "Static TV Head" Infiltrator, is the base model.** Variant 2 ("Wide-Aspect VR" Runner) is the Corporate variant and Variant 3 ("Broadcast Brute" Enforcer) the Gangland variant. Recolour every glow to the game's colour rules (see the brief). |
| `cyborg_casino_enforcer.jpg` | The Marketplace cyborg variant (GDD §9.2), and the starting point for the Golden Zone variant | Same unit as the base; recolour the screen to cold white. |
