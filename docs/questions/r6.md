# R6: DESIGN-TBD markers taken off approved placeholders

No questions from this task — comment and doc-comment editing only, no new design decisions.

## Method

Went through `docs/OPEN_QUESTIONS.md` §D ("Owner's placeholder review", September 26, 2026) and
built the set of grey-box (GB) and full-build (FB) items the owner approved as is: every GB/FB item
*not* listed under "Changes", "Tune after playtesting" or "Later design rounds". Per the task brief,
every "From build phase 2" (P2) item stayed open regardless of its own status (none of them have been
reviewed yet), and a "Changes" item kept its marker even though the change itself is recorded in the
GDD, since the change may not be the same value the placeholder still carries. For each `DESIGN-TBD`
marker in `scripts/`, `data/` and `tools/`, matched it to the GB/FB item its text answers (by its own
citation, or by the value/behaviour it describes); removed the marker only on a clean match to an
approved item, re-wording the comment to keep its explanation as a normal doc comment and citing the
item number. Left alone: any marker tagged with a `docs/questions/<task-id>.md` task file (every one
of those is a later task's own open question, not reviewed in the Sept 26 pass), anything about fences
or wall-running (B5 is running now), anything in a skipped C2/B5/E5a file, and anything I could not
tie to a specific approved item with confidence.
