# Task S1: the host cyborg stands out

The owner's request (October 23, 2026, GDD §9.7, "Origin"): purple smoke rising off a host (a purple glow would also do),
so the player can pick it out of a crowd, cheaply enough not to hurt performance. Built as `HostSmoke`
(`scripts/enemies/host_smoke.gd`, `host_smoke.gdshader`): one draw call per host. Every number below is in
`data/enemies/cyborg.tres` (`CyborgTuning`'s "Host smoke" group, F6 "Host smoke" when it is open).

1. **How much smoke?** How strong, how thick and how tall should it be, and how far past the host's head should it
   reach? The GDD only says it should help "pick it out of a crowd more easily" without hurting performance.
   (GDD §9.7, Origin.)
   Placeholder: opacity 0.75 at the thickest (`host_smoke_strength`), billows filling 60% of each column
   (`host_smoke_density`), rising 0.7 m/s (`host_smoke_rise_speed`), a middle column 1.0 m wide at its base and
   2.2 m tall (`host_smoke_width`, `host_smoke_height`; a zone draws its cyborgs 1.2 times bigger, so 2.6 m in play),
   with a thinner column to each side. Chosen so a host reads at 100 m and a plain cyborg standing behind its smoke is
   only faintly tinted; an opacity of 0 turns it off. DESIGN-TBD in `cyborg_tuning.gd`.

   and should the smoke get a brighter, glowing core (the owner's "or a purple glow")? (GDD §9.7, Look and Origin;
   §9.1, fence pink.)
